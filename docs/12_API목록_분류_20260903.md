## 3. 지표누리 CSV — 분류 불가, 대체 제안
파일 열이 `유저ID·신청일자·종료일자·용도구분·사용목적`으로, 지표누리(index.go.kr) API를 **다른 이용자들이 신청한 이력**이다(543건 중 재난 관련 목적은 1~2건). 지표 목록·API 명세가 아니라 우리 분류에 쓸 수 없다.
대신 지표누리에서 볼 지표(국가지표체계, 대부분 시도 단위·연간):
- 자연재난 발생 및 피해(idx 1628 계열) — 재해연보와 동일 원천, 시도
- 재난관리기금 적립 현황, 지역안전지수, 소방공무원 1인당 담당인구, 응급의료기관 수 — 시도 단위라 **맥락 변수**로만
지표누리 API는 KOSIS와 같은 통계표 ID 체계라, 시군구가 필요하면 KOSIS 시군구 표를 직접 쓰는 편이 낫다.

## 4. 종합 — 착수 순서
1. **SGIS 인증키 발급**(사용자, 무료·즉시) → 자연재해 통계지도 4종·센서스 주택·농어가·도시화경계 수집기(제 몫). 격자 빈칸 2개(flood_risk_100y·semi_basement_r) 채움 가능성.
2. **지방재정365 12건 수집기**(제 몫, 키 불필요·요청주소 확보됨) → 정책·재정 렌즈 v0.
3. 통계연보 4+3종(요청주소 대기, docs/11 §2).
4. 나머지 파일형(외국인주민·등록장애인·수급자·인구감소지역 고시)은 KOSIS/행안부 다운로드.

**중복 경고**: SGIS 가구·인구와 주민등록을 같은 렌즈에 둘 다 넣으면 변수 중복(docs/09 §3 함정). 주민등록을 본선, 총조사는 검증·보정용으로 역할을 고정한다.
