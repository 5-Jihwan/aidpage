공개 데이터 안내

AidPage에는 서버 API가 없습니다. 사이트가 쓰는 파일이 곧 공개 데이터이고, 아래 주소에서 그대로 받을 수 있습니다. 개인정보는 어디에도 없습니다.

No server API — the site's own static JSON files are the public data. Base URL: https://5-jihwan.github.io/aidpage/

1. 지원 규칙 — 재난 지원 제도를 조건·금액·근거·기한으로

파일내용갱신
rules/cash.json재난지원금(주택·생계·소상공인·농어업)법령·고시가 바뀔 때. 매일 새벽 법령 개정을 감지
rules/relief_fund.json의연금(국민 성금) 배분 기준
rules/indirect.json간접지원 — 세금·보험료·공공요금 감면, 융자·보증
rules/insurance.json풍수해·지진재해보험 보험료 지원
rules/heat_cold.json폭염·한파 쉼터와 에너지 지원
rules/procedures.json신고 → 조사 → 확인서 → 지급 → 이의의 절차와 기한
rules/changelog.json지원 기준이 바뀐 이력(언제·무엇이·근거)기준 변경 시
rules/en.json위 규칙의 영어 오버레이(id별 label·summary·amount_text 등)규칙과 함께
data/ref/law/<MST>.json규칙이 인용하는 조문·별표 원문 스냅샷(국가법령정보 OPEN API)매일
 
{ "id": "cash.house_flood", "label": "…", "amount_krw": 3500000, "amount_text": "…",
  "conditions": { "housing": ["own","rent"], "damage": ["flood"], "special_zone": null },   // 키마다 교집합(AND of any-of)
  "channel": "auto_after_report | apply", "deadline_days_after_event": 10,
  "where": "…", "docs": ["…"], "basis": "규정 별표1 …", "basis_url": "https://www.law.go.kr/…",
  "rate_asof": "2026-08-19", "confidence": "verified | reported | estimate",          // 원문 확인 / 보도 기반 / 추정
  "law": { "mst": "279945", "name": "…", "art": "제4조", "annex": "별표1" } }
판정 엔진은 의존성 없는 ES 모듈 js/rules.js의 evaluate(rules, input, lang) 하나입니다. 브라우저와 Node에서 같은 코드가 돕니다.

data/live/*.json특보·재난문자·산사태·날씨·응급실 — 시점은 자료 상태에서
쓰실 때
· 결과는 "해당 가능성"입니다. AidPage는 심사하지 않으며 최종 판단은 관할 지자체입니다.
· 침수 이력은 "조사된 침수"의 기록입니다. 기록이 없다는 것이 안전하다는 뜻은 아닙니다.
· 도보 시간은 도로가 아니라 직선거리(67 m/분) 기준입니다.
· 원천 자료는 각 제공 기관의 이용 조건(공공누리 등)을 따릅니다. 이 저장소의 라이선스 표기는 준비 중입니다.
· 틀린 곳을 찾으셨다면 GitHub 이슈로 알려 주세요. 규칙 오류는 72시간 안에 고치는 것을 목표로 합니다.
