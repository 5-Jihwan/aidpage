# 지자체 "타입 시스템" 설계 — 선행연구 유무 확인과 우리 방식 (2026-09-04)

> 사용자 요구: ①행정학·정책학·재난방재 연구자가 지자체를 재난·정책·제도·사회 기준으로 유형화한 것이 있는지 확인, 없으면 직접 개발 ②국외 기준 참고 ③포켓몬 타입처럼 "악·벌레"식 복합 타입으로, 도→시·군→동으로 크게도 작게도 볼 수 있게.
> 앞선 문서: docs/09(문헌 스크리닝), docs/11(렌즈별 세분화), docs/11 §3-1(k=5 군집 안정성: 농촌 2유형만 유효 → 규칙 기반으로 전환).
> 논문화는 별도 다룸(여기서는 앱·데이터 설계만).

## 1. 선행연구 확인 결과 — 국내엔 없고, 국외엔 "원형(archetype)" 계열이 있다

### 국내
| 찾은 것 | 무엇을 유형화했나 | 우리와의 거리 |
|---|---|---|
| 박현수·권설아(2024) 지역안전지수 잠재계층 | 시군구 228 → 3계층, 입력이 안전지수 등급(자연재해 제외) | 가장 가까운 형식. 그러나 재난 축 없음·순환성 |
| 한국방재학회 수해 취약지역 4유형(현상태 지속가능·추가개발 가능·위험 잔존·전반적 취약) | 수해 취약지역(공간 단위)을 4유형 | 지자체 단위 아님, 단일 재난 |
| 쇠퇴지역 vs 도시지역 재난 취약요인 비교(디지털콘텐츠학회) | 지역 성격 2분 비교 | 유형화 아님 |
| 최적 재난대응을 위한 재난유형 구분(한국방재학회논문집) | **재난**의 유형(지자체 아님) | 우리 위해 타입 어휘 참고 |
| 군집분석을 이용한 수도권 도시의 유형화(KCI) | 도시 일반 특성 군집 | 재난 아님 |
| 구주영(2026) 재난관리 역량 5요소 | 광역 17, 회귀(유형 아님) | 변수 조작화 참고 |
| 재난관리 거버넌스 유형·특별지자체 역할(행정학·정책학 다수) | 거버넌스 **모형**의 유형(협력형·통제형 등) — 지자체를 분류한 게 아니라 제도 설계안을 분류 | 제도 렌즈 이름 짓기에 참고 |
**판정: 행정학·정책학·방재 어디에도 "지자체 단위 × 다중 렌즈(재난·취약·제도·정책·구조·기관) 유형화"는 없다.** 거버넌스 유형론은 있으나 대상이 제도이고, 방재 쪽 유형화는 대상이 공간(취약지역)이나 재난 자체다. 우리가 만드는 것이 첫 사례가 된다.

### 국외 (기준으로 삼을 것)
| 사례 | 방식 | 차용할 점 |
|---|---|---|
| **이탈리아 전 기초지자체 원형 분류**(NHESS 2025, "urban and rural settlement archetypes") | 전국 municipality를 군집 → **10개 대분류 + 18개 중첩 소분류(nested)** | 우리 "크게 보기/작게 보기"의 직접 선례. 상위 원형 안에 하위 원형이 들어가는 계층 구조 |
| **European Climate Risk Typology**(ECRT, NUTS3 1,379개) | 위해·노출·취약 3영역 합성 → 이름 붙은 유형(예: 도시·해안·저지대 등), 지도 탐색 | 이름 있는 유형 + 대시보드 탐색, 순위 없음 |
| ESPON Hazards 지역 유형 | 유사 위해 조합으로 NUTS3 군집, "상호작용 위해 수" | **복합 타입**(위해가 둘 이상 겹치는 지역) 개념 |
| 해안 위해 커뮤니티 유형(Ocean & Coastal Management 2017) | 취약 지표 군집 → 유형, 신규 지역은 **유사도 지수(HVSI)**로 배정 | 새 지역·새 연도를 기존 유형에 배정하는 규칙 |
| 홍수 사회취약 프로파일 SVP(IJDRR 2025) | 지표 상호작용을 군집한 다차원 프로파일 | "프로파일 = 여러 축의 조합" 표현 |
| 호주 ADRI LGA 분류 | 회복력 프로파일 분류 → 자원배분 | 정책 연계 방식 |
| 일본 JILPT 시정촌 지역유형(DP18-05) | 통계지표 주성분+군집으로 전국 시정촌 분류(비재난) | 구조 렌즈(도시·농산어촌) 이름 어휘 |
| 일본 국토교통성 도도부현별 재해리스크 에리어 | 위해 구역 면적·인구 비율 집계 | 시도 레벨 "타입 분포" 표현 |
공통점: **단일 점수가 아니라 "이름 있는 유형"**, 위해와 취약을 **조합**, 대분류→소분류 **계층**. 이 셋이 곧 포켓몬식 타입 시스템의 조건이다.

## 2. 우리 타입 시스템 — "악·벌레"처럼 읽히는 복합 타입

### 2-1. 어휘 (타입 사전 v0, 16개, 세 계열)
이름은 짧은 우리말 한 단어, 평가어 금지. 아이콘은 지도 칩용.
| 계열 | 타입 | 뜻(무엇이 강한가) | 판정 규칙(v0) | 기준 출처 |
|---|---|---|---|---|
| 위해 | **물** 💧 | 하천범람·침수 | 침수 이력 셀 비율 전국 상위 25% 또는 침수위험개선지구 ≥ 5 | 자연재해대책법§12 침수·유실위험지구, 격자 침수흔적 |
| 위해 | **산** ⛰ | 산사태·급경사 | 산사태 이력 셀 비율 상위 25% 또는 평균 경사 ≥ 15° 또는 붕괴위험지구 ≥ 3 | 급경사지법, 산사태 이력 |
| 위해 | **바다** 🌊 | 태풍·해일·풍랑 | 해안 접촉 + (해일위험지구 ≥1 또는 태풍 영향범위 빈도 상위 25%) | 해일위험지구, SGIS 태풍 영향범위 |
| 위해 | **눈** ❄ | 대설·한파 | 대설·한파 특보 빈도 상위 25%(코퍼스) | 기상 특보 이력 |
| 위해 | **볕** ☀ | 폭염 | 폭염특보 일수 상위 25% 또는 온열질환자/인구 상위 25%(시도) | SGIS 과거 폭염특보, 통계연보 15077974 |
| 위해 | **땅** 🪨 | 지진 이력 | 지진 피해 이력 또는 옥외대피장소 밀도 상위 25% | 재해연보 지진, 대피장소 |
| 위해 | **마름** 🏜 | 가뭄·고립 | 상습가뭄재해지구 또는 고립위험지구 ≥ 1 | 위험개선지구 유형 |
| 취약 | **노년** 🧓 | 고령·고령 1인세대 | 65세+ 상위 25% 그리고 65세+ 1인세대 상위 25% | 재난안전법§3 안전취약계층 |
| 취약 | **홀로** 🧍 | 1인세대 | 1인세대 상위 25%(노년 아닌 경우) | 같음 |
| 취약 | **이방** 🌐 | 외국인 주민 | 등록외국인/인구 상위 25% | 재난약자 매뉴얼 |
| 취약 | **돌봄** ♿ | 장애·아동 | 등록장애인/인구 또는 0~9세 비율 상위 25% | 같음 |
| 취약 | **살림** 🏚 | 저소득·주거취약 | 수급자율 상위 25% 또는 반지하·비닐하우스 거처 비율 상위 25% | 재해구호법, SVI 주거 테마 |
| 구조 | **도심** 🏙 | 고밀 | 인구밀도 상위 25% 또는 SGIS 도시 경계 안 | 지방자치법§2, SGIS 도시화 |
| 구조 | **들** 🌾 | 농어촌 | 농가+어가 비율 상위 25% 또는 읍·면 인구 비중 ≥ 50% | 농어업인삶의질법 농어촌 |
| 구조 | **섬** 🏝 | 도서 | 도서개발촉진법 지정 도서 보유 | 법정 목록 |
| 구조 | **접경** 🪖 | 접경지역 | 접경지역지원특별법 목록 | 법정 목록 |
제도·재정·기관은 타입이 아니라 **특성(ability)**으로 붙인다: "두꺼운 제도 / 얇은 제도", "자립 재정 / 의존 재정", "기금 충족 / 기금 미달", "의료 가까움 / 의료 멀음", "반복 선포"(특별재난지역 3회↑). 포켓몬으로 치면 타입은 2개, 특성은 1~2개, 능력치는 숫자 카드.

### 2-2. 복합 타입 규칙 ("악·벌레")
- **주 타입** = 위해 계열에서 규칙을 만족하는 것 중 가장 강한 것(점수: 임계 초과 정도의 표준화 값). 없으면 **평온**(위해 타입 없음)으로 표기하되 "기록 없음 ≠ 안전" 문구 고정.
- **부 타입** = 취약 계열 우선, 없으면 구조 계열에서 가장 강한 것.
- 표기: `산·노년`(진안군), `물·도심`(강서구), `바다·들`(고흥군), `평온·도심`(영통구).
- 세 개 이상 해당하면 카드에 "보조 타입"으로 작은 칩. 타입은 최대 2개만 크게 — 읽히는 한계.
- **동점·경계**: 임계에 ±5% 안이면 "경계" 표시(포켓몬의 '?'). 서열 숫자는 어디에도 쓰지 않는다.

### 2-3. 크게 보기 / 작게 보기 (도 → 시·군·구 → 읍·면·동)
| 레벨 | 타입 산출 | 표현 |
|---|---|---|
| 읍·면·동 | 격자 emd 속성(침수·산사태 이력, 경사, 65+, 1인, 고령1인) + 시군구 상속(해안·법정 목록) | 이중 타입. 취약 계열은 주민등록이 있어 정확, 위해는 격자 있는 곳만 |
| 시·군·구 | §2-1 규칙 전부 | 이중 타입 + 특성 + 능력치 카드(현 sgg_demo·격자·riskzone·통계연보) |
| 시·도 | 시군구 타입의 **분포**(인구 가중) | "경북: 산 48% · 바다 22% · 물 10% … / 노년 61%" 막대. 시도 자체엔 단일 타입을 붙이지 않는다(17개라 사분위 무의미). 시도 능력치는 통계연보 sido_disaster(1인당 피해·자부담 비율) |
| 전국 | 타입 분포 지도(주 타입 색) | 탐색 진입점 |
줌인하면 시도 분포 → 시군구 타입 칩 → 읍면동 타입 칩으로 같은 어휘가 내려가고, 줌아웃하면 집계된다. 이탈리아 10+18 중첩 원형과 같은 구조를 **규칙 기반**으로 얻는 셈이다.

### 2-4. "상성표"의 올바른 쓰임
포켓몬 상성표를 그대로 옮기면 지역 서열이 된다. 대신 **타입 → 필요한 대비·제도** 표로 쓴다.
| 주 타입 | 우선 확인 | 연결되는 지원·제도 |
|---|---|---|
| 물 | 침수 이력 셀, 지하차도, 반지하 | 풍수해보험(주택·온실), 침수 피해 지원금, 우수저류시설 |
| 산 | 산사태 예보, 급경사지 지점 | 산사태 취약지역 지정, 급경사지 정비 |
| 바다 | 해일·풍랑 특보, 어선 | 어선원 재해보험, 어업인 안전보험 |
| 볕 | 무더위쉼터, 온열질환 | 에너지바우처, 저소득층 에너지효율개선 |
| 노년(부) | 대피 도움, 응급안전 | 독거노인 응급안전안심서비스, 노인맞춤돌봄 |
| 이방(부) | 다국어 안내 | 1345·다누리, 외국인 의료지원 |
이 표는 이미 만든 지원 찾기 규칙 52·복지 367과 "지역 특성 가중"을 타입 어휘로 다시 묶는 것이라 새 데이터가 없다.

### 2-5. 왜 군집이 아니라 규칙인가 (09-04 검증 결과)
k=5 군집은 부트스트랩에서 농촌 2유형(.88·.75)만 살고 도시 3유형은 .58~.64로 무너졌다. 규칙 기반은 ①재현 가능 ②지자체 담당자에게 설명 가능 ③연도가 바뀌어도 같은 규칙 ④신규 단위(읍면동)에 즉시 적용 — 해안 위해 유형 연구의 HVSI(유사도 배정)와 같은 역할을 임계 규칙이 한다. 군집은 임계값 튜닝과 "자연스러운 조합"(어떤 타입 쌍이 실제로 자주 붙는가) 확인에만 쓴다.

- 서울 '물'은 침수흔적도가 촘촘한 영향이 남아 있다(caveat 동봉). 세종 '물'은 침수지구 밀도로 성립(flood_r 낮음) — 문구로 구분 필요.
- 파일마다 `meta.rules`·`thresholds`·`caveats`를 동봉해 규칙·기준일이 데이터와 함께 이동한다.
