# 지역 서랍 × 기존 지도 기능(3D·시설·날씨 색면) 연동 스크리닝 — 2026-09-03

> 대상 설계: 전후 비교 목업 https://claude.ai/code/artifact/0a728558-e1ff-4cb8-b383-a5ff24b417d9 (왼쪽 패널 유지 · 선택 지역 외 옅어짐 · 오른쪽 "이 지역은" 서랍).
> 질문: 이미 있는 3D(지형·건물·격자 기둥), 시설(아이콘/지층 히트맵/구역별), 날씨 색면(온도·미세먼지·바람)을 이 설계에 어떻게 얹는가. 충돌 지점과 규칙.

## 0. 결론

- **"바깥 옅어짐"은 새 레이어가 아니라 기존 행정면 레이어의 상태값으로 구현한다.** sgg-fill·sido-fill·emd-fill에 `focus` feature-state를 주고, 선택 밖 피처만 흰색 반투명으로 칠한다. 지오메트리 연산(전국−선택지역) 없음, 레이어 추가 없음, 폰에서도 공짜.
- **날씨 색면과 옅어짐은 동시에 켜지 않는다.** 색면의 목적이 "옆 지역과 비교"라서 바깥을 지우면 목적이 사라진다. 서랍이 열려 있을 때만 옅어짐(포커스 모드), 색면을 켜면 포커스가 자동 해제된다(반대도 같음). 지도 위 오버레이는 한 번에 한 종류라는 규칙을 이번에 세운다(지금도 날씨 색면과 히트맵이 겹치는 미해결 문제가 있음).
- **3D는 그대로 공존한다.** 지형·힐셰이드 위에 옅어짐이 얹혀 선택 지역이 입체로 도드라진다. 건물 압출(bldg-3d)만 바깥에서도 선명하게 남는 문제가 있어 포커스 모드에서는 건물 불투명도를 0.85→0.35로 낮춘다. 격자 3D 기둥은 원래 선택 시군구 안에서만 생기므로 충돌 없음.
- **시설은 이미 선택 지역으로 클립되어 있어 충돌 없음.** 서랍의 시설 총량 행에서 "지도에서 보기"를 누르면 해당 종류를 켜고 표시 모드(아이콘/지층/구역별)는 사용자 설정을 따른다.
- **레이어 순서**: 행정면(옅어짐 포함) < 격자 < 시설 히트맵 < 시군구 라벨 < 읍면동 라벨. 옅어짐은 행정면 자체의 색이라 삽입 위치 문제가 생기지 않는다(히트맵 라벨 가림 사고의 재발 여지 없음).

## 1. 충돌 매트릭스

| 기존 기능 | 옅어짐(포커스) | 서랍 | 규칙 |
|---|---|---|---|
| 날씨 색면(온도·PM·바람 화살표) | **충돌** — 바깥 색이 지워져 비교 불가 | 서랍 왼쓱 태그 "현재 특보 없음"만 | 상호 배타. 색면 켜면 포커스 off·서랍은 열려 있어도 됨(서랍은 정보, 포커스는 시각). 색면 범례에 "지역 비교 모드"라고 표기 |
| 3D 지형·힐셰이드 | 공존. 옅어짐이 지형 위에 얹힘 | — | 변화 없음 |
| 3D 건물(bldg-3d, z14+) | 부분 충돌 — 바깥 건물이 선명 | — | 포커스 모드에서 fill-extrusion-opacity .35. 지역 밖 건물 필터는 불가(건물 피처에 시군구 속성 없음)라 불투명도로 처리 |
| 격자(면·3D 기둥) | 공존 — 격자는 선택 시군구 안에만 | 서랍 재난 이력 행 "지도에서 보기" → 격자 속성 칩 전환 | 서랍에서 속성 바꾸면 왼쪽 칩도 동기화(단일 상태) |
| 시설 아이콘/클러스터 | 공존 — 클립됨 | 시설 총량 행 "지도에서 보기" → 종류 on | 표시 모드는 사용자 설정(safepic.shMode) 유지 |
| 시설 지층 히트맵·구역별 | 공존 — 클립됨 | 같음 | 구역별 모드는 시군구 선택 시 읍면동 개수 색면인데, 이것도 "색면"이라 날씨 색면과는 상호 배타(기존 미해결 문제를 같은 규칙으로 해결) |
| 태풍 경로·특보 배너·wx-fx 연출 | 공존 | 태그 1개 | 변화 없음 |
| 시뮬레이터(sim.js) | 충돌 가능 — 시뮬레이터는 지도 클릭을 가로챔 | 서랍 닫힘 | 시뮬레이터 진입 시 서랍 자동 닫기, 포커스 off(경로가 지역 밖으로 나갈 수 있음) |
| 검색·드릴다운 | 공존 | 지역 바뀌면 서랍 내용 갱신 | 서랍은 상태를 따라감. 국가 레벨로 돌아가면 닫힘 |
| 폰 시트 | 옅어짐 동일 | 서랍 없음 → 시트 두 탭 | 두 시트 동시 금지 |

## 2. 상태 모델 (한 줄로 끝나는 규칙)

```
mapOverlay ∈ { none, wx(온도·PM·바람), shelterArea(구역별 개수) }   // 색면류는 한 번에 하나
focus      = drawerOpen && mapOverlay === none                       // 옅어짐은 서랍 열림 + 색면 없음일 때만
bldgOpacity = focus ? .35 : .85
```
- 색면을 켜는 어떤 조작도 `mapOverlay`를 바꾸고 다른 색면을 끈다(날씨 셀렉트, 시설 구역별 모드).
- 서랍은 정보 컨테이너라 색면과 무관하게 열려 있을 수 있다. 시각 효과(focus)만 물러난다.
- 시뮬레이터·국가 레벨 복귀는 `drawerOpen=false`.

## 3. 구현 메모

- 옅어짐: `map.setFeatureState({source:'sgg', id}, {focus: 0|1})`를 선택 변경 시 전 피처에 한 번. paint: `fill-color`를 `['case', ['==',['feature-state','focus'],0], '#f4f7fb', 기존색]`, `fill-opacity` 기존 base에 `focus==0 → .62` 추가. 읍면동 레벨에서는 같은 시군구의 다른 읍면동만 옅게, 시군구 밖은 이미 sgg-fill이 덮음.
- 라벨: 바깥 sgg-label·emd-label `text-opacity` .35(포커스 시). 시도 라벨은 그대로.
- 건물: set3D와 독립된 `applyFocus()`가 bldg-3d opacity를 조정. set3D 안에서 ensureBldg 후 applyFocus 재호출.
- 서랍 모듈 `js/region.js` lazy import(sim.js 방식). app.js에는 진입점(요약 줄)과 상태 전이만.
- 계측: `region_open`, `region_to_find`, `region_maplink`(지도에서 보기) 3종.

## 3-1. 구현 후 확인(09-04, v=20260904c)
- **바깥 옅어짐은 이미 있었다.** app.js `applyFocus()`가 선택 시군구·읍면동 밖을 focus-mask(흰 55%)로 덮고 그림자·링을 그린다(08-27 도입). 이 문서 §0·§3의 feature-state 방식은 구현 도중 중복으로 판명되어 제거했고, 서랍은 `applyDrawerFx()`로 3D 건물 불투명도(.35)만 낮춘다.
- 마스크는 sido-fill 아래 층이라 날씨 색면·구역별 색면이 그 위에 그려진다 → §1의 "상호 배타" 규칙은 자동으로 충족(색면이 마스크를 덮음). 별도 상태 전이 코드 없음.
- 서랍 열림 시 `.stage.has-drawer`로 지도 컨트롤(bottom-right)과 상단 스택(.mapstack)을 346px 이동. 시뮬레이터 연동은 미구현(지역이 바뀌면 시뮬레이터가 닫히므로 실사용 충돌 낮음).
- 계측 3종 워커 반영. 폰은 서랍·버튼 없음(칩만).

## 4. 사용자 결정 필요

1. 색면 켜면 포커스를 끄는 규칙(위 2절)에 동의하는지. 대안은 "색면 위에도 바깥을 30%만 옅게"인데 비교 가능성이 반쯤 죽어 추천하지 않음.
2. 포커스 모드에서 바깥 건물을 흐릴지(추천) 그대로 둘지.
3. 서랍 열림 기본값: 지역 선택 시 닫힘(요약 줄만) — docs/08 R2 규칙 유지 추천.
