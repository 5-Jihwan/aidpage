# SafePic — 앞으로의 구상 (2026-08-24)

## 0. 한 문장
**회복하지 못한 사람이 신청조차 못 하는 첫 고리를 끊는다.** 지도·날씨·시설은 전부 그 문장을 위해 존재하고, 판단 기준도 하나다: *이 기능이 "신청 못 하던 사람"을 한 명이라도 신청하게 하는가.*

## 1. 네 층위 — 제품의 뼈대
| 층 | 질문 | 현재 | 다음 |
|---|---|---|---|
| **지금** | 오늘 내 동네는 어떤가 | 시설 19종·판정 줄·오늘 할 일(계절) | 특보·날씨 히트맵·24h 타임라인·애니메이션 (S1·S2) |
| **과거·확률** | 여기서 무슨 일이 있었나 | 관악 격자 침수 이력 | 재해연보·특보 이력·"이 동네의 8월" 달력·전국 순위 (S6) |
| **미리** | 어디가 더 위험하고, 무엇부터 고쳐야 하나 | 동 2개 비교·MathML 수식 | 격자 BCR 시뮬레이터·개선지구 대조 (S7) |
| **나** | 내 상황엔 무엇이 있나, 어떻게 신청하나 | 상황 카드 7·규칙 51·서류·이유·인쇄·대리 | 조문 펼침·자치법규·평상시 복지·응급실 가용병상·기한 경과자용 안내 (S3·S4·S2) |

**투자 비중**: 나 50% · 지금 30% · 과거 15% · 미리 5%. "미리"는 학술 가치는 높지만 첫 고리와 가장 멀다.

## 2. 일정 — 세 마디
### 마디 A · 키 들어오는 날 ~ 1주: "살아 있는 사이트"
- S1 날씨·특보(패키지① 또는 data.go.kr) → 히트맵 라디오·바람 화살표·24h 타임라인·특보 애니메이션·시설 자동 ON
- E-Gen 응급실 가용병상 → "지금 받아주는 응급실"
- JUSO → 지하차도·펌프장·심리센터 좌표
- 통합대피소로 4종 교정
- **완료 기준**: 폰에서 동 하나 골랐을 때 30초 안에 "지금 뭐가 위험하고, 뭘 하고, 어디로"가 읽힘
- **그 뒤 링크드인 공유** (주어는 "문제", 근거는 JCCM 발견 + Billings 2022)

### 마디 B · 2~4주: "신청을 끝까지"
- S3 법령: 조문 펼침·개정 자동 감지·우리 구 조례(지자체 추가 지원)
- S4 복지로: 재난과 별개로 받을 것
- 기한 경과자 경로: "지났어도 가능한 것"(연장 소명·의연금·간접지원) 전용 카드
- 리스크 §1c 상위 3건: 금액 옆 "심사 아님", 기준일 6개월 배지, 제보 관리 삭제
- **완료 기준**: "신고했는데 소식이 없어요"·"기한 지났어요" 두 경로가 막다른 길 없이 끝남

### 마디 C · 1~3개월: "과거와 연구"
- S6 이력·통계(재해연보·특보 이력·개선지구·싱크홀·ASOS) → "이 동네의 8월", 전국 순위
- S5 Worker: 뉴스(선택형)·레이더/위성
- 한국어 Warning Lexicon 공개(RQ1), 주민센터 1곳 파일럿(RQ5)
- S7은 C 말미 또는 박사 과정에서

## 3. 연구 트랙 — 도구가 논문을 낳는 순서
1. **JCCM 후속**: 본 논문 발견(회복 격차) → SafePic 설계 논리 → RQ4(매칭 카드가 "회복 못한 집단"의 신청 의도·행동을 바꾸는가) 온라인 실험. 데이터는 사이트 안 선택형 설문 + 주민센터 파일럿
2. **한국어 Warning Lexicon**(RQ1): 특보 20문구→전 유형 템플릿, 재난문자와 비교 실험. 국내 첫 사례
3. **내 동네 이력과 위험 개인화**(RQ2): S6 후 A/B
4. 산출물 순서: 워킹페이퍼(툴 설명+설계 근거, 문헌검토 §0 기반) → 실험 논문 → 박사 지원서 writing sample

## 4. 공개·커뮤니케이션
- 링크드인: 마디 A 완료 직후 1회. 이후는 마디 B 완료 때 "신청을 끝까지" 업데이트 1회. 잦은 포스트 금지
- 포트폴리오 Projects 카드: "Live · Preview" → 마디 A 후 "Live"
- 피드백 창구: 사이트 안 제보 + GitHub Issues + 형(현대오토에버)·경로당 1곳 실사용 관찰
- 공식 기관 접촉은 마디 B 후: 행안부 재난구호과·관악구 안전재난과에 "무료 도구" 안내 메일 1통 (요구 X, 정보 제공)

## 5. 지키는 것
- 키는 브라우저 밖 · 좌표 안 지어냄(공식 지오코더만) · 군 시설 비공개 · 숫자엔 근거·기준일 · 심사하지 않음
- 단일 UI + 큰 글씨(별도 시니어 버전 없음) · 게이미피케이션 없음 · 거짓 안심 없음(데이터 없으면 "없음"이라 말함)
- 배포 전 `node --input-type=module --check` + 헤드리스 콘솔 + `?v=` 증가
