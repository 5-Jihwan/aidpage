## 3. 세분화의 원칙 (문헌 스크리닝 §3 승계)
- 타입은 렌즈 안에서만 정의하고, 렌즈 간 결합은 카드 나열로만.
- 각 타입은 **임계 규칙(전국 상위 25% 등)** 또는 **법적 목록(인구감소지역·특별재난지역)**으로 정의한다. 군집은 탐색용, 카드의 타입은 규칙 기반 — 재현 가능하고 설명 가능해야 지자체 담당자가 받아들인다.
- 이름은 설명형, 평가어 금지. "취약형"은 법정 용어(안전취약계층)를 따르는 취약 렌즈에서만 쓴다.
- 데이터 기준월·출처를 타입 옆에 항상 표기.

## 3-1. 1차 해(k=5) 안정성 검증 결과 — 2026-09-04 (scripts/typology_stability.py)
Hennig(2007) 군집별 부트스트랩 Jaccard(B=50, 재표집 안 비교) + 대안 사양 재현율.

| 군집(09-03 임시 이름) | n | Jaccard | 판정 | 뜻 |
|---|---|---|---|---|
| 내륙 산간 고령형 | 62 | .88 | 매우 안정 | 이름 붙여도 됨 |
| 해안 고령 농어촌형 | 34 | .75 | 유효 | 이름 붙여도 됨(경계 주의) |
| 도심 저위험형 | 70 | .64 | 불확실 | 패턴은 있으나 소속 불확실 → 이름 보류 |
| 도심 저지대 침수이력형 | 45 | .61 | 불확실 | 같음 |
| 도농복합 산지형 | 44 | .58 | 해체 | 유형으로 세우지 않음 |

대안 사양 일치율: 해안 제외 .82, 경사 제외 .75, 위험개선지구 제외 .65, 로그 미적용 .62, 위해 변수만 .64, 취약·구조만 .60 → **위험개선지구·로그 변환 선택이 결과를 크게 흔든다**(Tate 2012의 "귀납형은 지표 세트에 민감"과 일치).
시/군/구 분리 군집(k=3)은 부분집합 안에서 더 또렷하다: 구는 침수 이력 0 / 0.2 / 0.35로 갈리고(서울 자료 촘촘함의 영향 포함), 시는 산지·해안·내륙평지, 군은 해안·내륙산지 둘로 갈린다.

**결론(방법 전환)**: 255개 전체를 한 번에 k-means로 묶는 방식은 농촌 두 유형만 살린다. docs/11 §3 원칙대로 **렌즈별 규칙 기반 타입**(임계·법정 목록)으로 가고, 군집은 규칙의 임계값을 고를 때 참고만 한다. 도시 쪽은 침수 자료 균질화(SGIS 홍수위험지도) 전까지 "도심형" 하위 구분을 보류한다.
⚠ 구현 교훈: 부트스트랩 Jaccard를 원 전체 집합과 비교하면 재표집 누락(~37%) 때문에 상한이 .63으로 눌려 전부 "해체"로 오판한다 — 반드시 재표집 안에서 비교.
