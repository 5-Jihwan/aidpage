### ★3 해석 검증 + 파일럿

- **전문가**: 지도교수 경유 행정법 1인. 의연금·간접지원 해석 위주.
- **파일럿**: 진안 인맥으로 경로당 또는 주민센터 1곳, 2일. 관찰 항목 = 상황 카드 선택 가능 여부·인쇄 카드 이해·대리 경로 인지. **논문화하려면 성균관대 IRB 필요** → 지도교수와 사전 협의. 관찰만 하고 논문화 안 하면 IRB 불요.
- **완료 기준**: 규칙 52건 중 사람이 확인한 비율을 화면 '방법과 한계'에 숫자로 명시.

- **저장소 분리 불필요**: 격자·위험 지점·특보가 이미 있어 aidpage 안의 모듈(js/sim.js + js/sim_worker.js)로 끝난다. 별도 저장소는 ①도로 그래프를 시군구별로 미리 만들어 브라우저에서 돌릴 때(수백 MB → 데이터 전용 repo) ②라우팅 엔진을 직접 띄울 때(서버·운영비 발생, 비권장) ③연구용 도로망 보행시간 계산(aidpage-research, 재현성·DOI)뿐.
