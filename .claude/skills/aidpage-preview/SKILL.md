# aidpage-preview

## 절차
1. 저장소 루트에서 서버를 띄운다.
   ```
   python -m http.server 8791
   ```
2. 확인할 상태가 여럿이면 루트에 `wrap_<이름>.html`을 만든다. `wrap_*.html`은 gitignore라 배포되지 않는다.
3. 실제 Edge로 캡처한다.
   ```
   node scripts/shot_cdp.mjs <url> <out.png> [대기ms] [폭] [높이]
   ```
4. 사용자에게 보여 주고 판단을 받은 뒤 커밋한다.

## wrap 파일 짜임
- 390px 폭 iframe을 나란히 놓고 각각 `src="index.html?a"`처럼 쿼리를 달리한다.
- 각 iframe의 `data-*`에 상태 값을 적고, load 이벤트에서 입력을 채워 제출한다.
- 규칙 로드 시점을 알 수 없으므로 결과가 뜰 때까지 500ms 간격으로 되풀이한다.
- `?i=<번호>`로 한 칸만 볼 수 있게 둔다.

## 주의
- 헤드리스 브라우저를 쓰지 않는다. 지도가 소프트웨어 렌더링되어 3분 넘게 걸린다. `shot_cdp.mjs`는 그래서 실제 창을 띄운다.
- 합성 터치는 안드로이드 크롬의 네이티브 스크롤 경합을 재현하지 못한다. 시트 드래그 같은 터치 동작은 실기기 확인을 사용자에게 요청한다.
- worktree에는 wrap 파일이 없다. 기존 wrap이 필요하면 메인 체크아웃에서 가져온다.
- 서비스워커가 옛 셸을 잡고 있을 수 있다. 화면이 안 바뀌면 `?v=`와 `sw.js`의 `VERSION`을 먼저 본다.
