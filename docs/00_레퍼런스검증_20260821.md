## C. 공백 검증 — "성립"
- WPA/레버리지 지수 비유를 재난에 쓴 선례 **없음** (학술·실무 모두). 단 수학 자체는 표준 회피손실 BCA(FEMA BCA Toolkit, NIBS 6:1)이므로 **새로운 건 프레이밍+격자 단위 레버리지 순위+법제 매칭 결합**.
- 가장 가까운 선행: ① IJDRR 2026 노르웨이 H3+RF 도시침수지수(보험 손해이력 130만 건) — 취약성만, 개입 반사실 없음 ② CLIMADA(ETH) CostBenefit 모듈 — 적응조치 B/C, H3·법제 없음 ③ BN-FLEMOΔ(NHESS 2025) 확률적 손실모델로 적응계획
- 국내: GIS(공공)와 혜택조회(보조금24·토스)가 **분리**돼 있고 "내 필지 위험→기대피해→수혜 항목"을 잇는 건 없음. 정부는 2026-07-22 **중앙합동 재난피해자 지원센터**(오프라인 원스톱) 신설 → 정책 수요 있음, 디지털 매칭은 부재.

## D. 기술 스택 후보
- 규칙엔진: **OpenFisca**(Rules-as-Code, 佛정부/NZ/바르셀로나 채용) 또는 PolicyEngine
- 위험모델: CLIMADA 포크, H3 res8(0.737 km²)/res9(0.105 km²) 공식표 확인
- 데이터: safetydata.go.kr API, floodmap 침수심 API(0.5/1/2/5m, 30/50/80/100년), 산사태위험지도 OpenAPI, SGIS 집계구, 건축물대장 API
- 주의: 침수지도·자연재해저감종합계획 B/C는 **위험지구 단위 PDF**라 격자 단위 공개 데이터 없음 → 직접 면적가중 보간 필요
