# AidPage 카카오톡 채널 — 설정 가이드 (2026-09-02)

코드는 끝나 있다(Worker `POST /kakao/skill`, 사이트 채널 버튼·딥링크). 남은 것은 **카카오 쪽 콘솔 작업 4단계**이고 전부 사용자 몫이다. **어떤 키도 필요 없다.**

## 0. 무엇이 만들어졌나
| 위치 | 내용 |
|---|---|
| `worker/src/kakao.js` | 오픈빌더 스킬 서버. 발화를 키워드로 분류 → 특보·산사태 예보·예비특보·재난문자(사이트가 공개 중인 data/live/alerts.json) → 카카오 응답 규격(simpleText + basicCard + quickReplies) |
| `worker/src/index.js` | `/kakao/skill` 라우트(IP 속도제한 제외), `/route`(카카오 도보 길찾기 자가검증 프록시, `KAKAO_REST_KEY` 없으면 no_key) |
| `js/app.js` | `KAKAO_CHANNEL` 상수(채널 공개 ID, 비어 있으면 버튼 숨김), `#g?sgg=…&emd=…&sido=…&tab=…` 딥링크(챗봇 카드가 지역을 바로 연다) |
| `index.html` | 서랍 "💬 카카오톡 채널 추가" 링크, 방법·한계에 "카카오톡으로 물어보기" 문단 |

챗봇이 알아듣는 말: `관악구 특보` · `진안군 재난문자` · `대피소` · `지원 찾기` · `내 동네 등록 관악구`(다음부터 지역 생략) · `도움말`. 시·도만 말하면(`서울 특보`) 시·도 단위로 답하고, `중구`처럼 겹치는 이름은 시·도를 되묻는다.

개인정보: 오픈빌더가 주는 봇 사용자 키를 해시한 값에 "동네 이름"만 KV에 180일 저장. 발화 원문·전화번호·카카오 계정은 받지도 저장하지도 않는다.

## 1. 채널 만들기 (카카오톡 채널 관리자센터 center-pf.kakao.com)
1. 새 채널 → 이름 **AidPage**, 카테고리 공공·사회, 프로필 = og.png 계열 이미지.
2. 채널 홈 URL `https://pf.kakao.com/_XXXXX`의 **`_XXXXX` = 채널 공개 ID**. 이것만 필요하다.
3. 검색 허용·홈 공개 ON. (비즈니스 인증은 알림톡 대량 발송에만 필요 — 지금은 불필요)

## 2. 사이트에 채널 연결
`js/app.js`의 `const KAKAO_CHANNEL = '';` → `'_XXXXX'`로 바꾸고 `?v=` 한 단계 올려 푸시. 버튼 링크는 `/friend`(추가)·`/chat`(대화)이고 앱 키·SDK를 쓰지 않는다.

## 3. 챗봇 만들기 (카카오 i 오픈빌더 i.kakao.com)
1. 오픈빌더 → 봇 만들기 → 카카오톡 챗봇 → **채널 연결**(1에서 만든 채널).
2. **스킬** 메뉴 → 생성: 이름 `aidpage`, URL `https://safepic-api.safepic.workers.dev/kakao/skill`, 저장 → "스킬 테스트"에 아무 말 넣고 응답 JSON이 오면 OK.
3. **시나리오 → 폴백 블록**: 응답 타입을 "스킬데이터 사용"으로, 스킬 = `aidpage`. (모든 발화가 폴백으로 오게 두면 의도 블록을 따로 만들 필요 없다.)
4. **웰컴 블록**(선택): 스킬데이터 사용 + 같은 스킬 → 첫 대화에 도움말이 나온다.
5. 우상단 **배포**. 봇 테스트 창에서 `관악구 특보`, `내 동네 등록 진안군`, `특보` 순서로 확인.
6. 오픈빌더는 응답을 **5초** 안에 요구한다 — Worker는 KV 캐시(특보 5분·지역 인덱스 1일)로 보통 1초 안이다.

## 4. 운영
- 채널 "소식"은 수동 게시(무료). 장마·태풍 전 "지원 신청 10일 기한" 같은 한 줄이 적합.
- 알림톡·친구톡(대량 발송)은 비즈니스 인증 + 발송 대행 비용 → 보류. 개인 알림은 이미 웹푸시가 맡는다.
- 상태 확인: `GET https://safepic-api.safepic.workers.dev/kakao/skill` → `{status:"ok", version:"kakao-1"}`.
- 발화 패턴을 늘리려면 `kakao.js`의 `KW` 표만 고치면 된다.

## 5. 카카오 키는 어디에 (요약)
| 키 | 필요한가 | 두는 곳 |
|---|---|---|
| JavaScript 키 | 채널·챗봇엔 불필요. 장소 검색 SDK를 쓸 때만 | 공개 코드에 넣어도 되는 키(콘솔 **도메인 제한** 필수: 5-jihwan.github.io). 시크릿 아님 |
| REST 키 | 도보 길찾기(2단계) 시험할 때만 | `cd worker && npx wrangler secret put KAKAO_REST_KEY` (Worker 시크릿). **GitHub Repository Secret 아님** — Actions는 카카오를 부르지 않는다 |
| Native 키 | 불필요 | 안드로이드·iOS 네이티브 앱 전용. PWA는 안 쓴다 |
| 도보 길찾기 API | 문서상 제휴 파트너 전용 | 키 등록 후 `GET /route?from=126.95,37.48&to=126.93,37.47` 로 자가검증 → `ok`면 2단계 진행, `error:403`이면 제휴 미승인 |
